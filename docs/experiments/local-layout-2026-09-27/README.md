# Острова, локальная компоновка и скрытые цепи

Откройте `comparison.html`. Кнопки L1/L2/R6/D2 выбирают четыре указанных блока Telemetry; доступны полные платы, остальные блоки и модули. Переключатель скрытых цепей включает также земли и пересчитывает метрики выбранного вида, не меняя вход решателя. Сравнение «до» — последний глобальный тест со штрафами за пады, а не Legacy.

Виды «Блок с дочерними» показывают семейство целиком. У current_iso это 12 компонентов, тогда как исходный SVG блока показывает лишь 5: семь компонентов дочерних current_hdc/current_hldo/current_secondary отсутствуют на нём, хотя занимают место рядом с U2 при локальной сборке. Нельзя считать всё пустое место на изображении отдельного блока свободным для перемещения.

## Установленные причины

- L1–U10 и L2–U12 уже имеют по две явные критические связи (`coreIsland`, строки 254–255 исходного telemetry-design/pcb-placement-placer.js). Их внутренние положения выбирает TypeScript solver двухкомпонентного острова. Далее пара жёсткая. Этот solver считал расстояния до центров с коэффициентом 10 000, но не проход через чужую площадку. Поворот с ближней и дальней площадкой выигрывал по сумме расстояний, хотя дальнюю связь перекрывала ближняя площадка. Добавлен отдельный штраф за каждый пересечённый чужой пад и кандидаты с точным выравниванием по заданным парам/их среднему смещению. Используется парный clearance. Обе пары остаются в maxDistance=5 и больше не пересекают чужие площадки.
- D2 не имеет общей цепи HARVEST_P с C56/C57, однако автоматический passive-net island объединял всех оставшихся пассивных участников, когда общую цепь имели хотя бы два из них. D2 замораживался внутри этого острова, поэтому варианты внешнего блока не могли подвести его к C55. Теперь каждый участник должен иметь общую выбранную цепь; иначе компоненты размещаются обычным решателем в контексте блока. Расстояние центров площадок D2.1–C55.1 сократилось 15.02 → 7.85 мм.
- current_iso включает дочерние блоки. Проверка «все компоненты имеют одно имя блока» отключала ему net candidates, beam, новые штрафы и локальный postrefine. Теперь тот же ограниченный по числу примитивов поиск применяется и к таким блокам; дочерние острова и блоки остаются жёсткими. R6/R8/U2 уже имеют явный kelvin_N path (строка 269 исходного скрипта).
- R6.2 присутствует в pin/net/footprint данных и подключён к I_OUT. В строке 283 исходного скрипта I_OUT явно указан в ignoredSignals вместе с GND, V_MEAS_N и HARVEST_P. Отсутствие redline в прежнем SVG — следствие настройки, не потеря цепи. Исключение также влияет на некоторые метрики и кандидаты; явные правила пути остаются активны. Настройка входа сохранена. Добавлены диагностический вид и предупреждение с конкретными цепями/падами.

## Результат для указанных блоков Telemetry

| Блок | Пересечения с падами до → после | Длина MST, мм до → после |
| --- | ---: | ---: |
| lte_power | 17 → 6 | 60.13 → 47.81 |
| logic_power | 7 → 4 | 26.50 → 22.80 |
| current_iso | 6 → 4 | 28.91 → 30.82 |
| hv_neg | 5 → 3 | 56.21 → 56.91 |

Полная Telemetry остаётся геометрически допустимой, но глобальные показатели ухудшились: MST 2579.89 → 2589.80 мм, линия–линия 287 → 320, линия–пад 362 → 365. Это исправление конкретных механизмов локальной сборки, не универсальная победа по качеству полной платы. Поиск стал дороже: единичный прогон Telemetry 422 с, ряд крупных блоков с дочерними группами занимает минуты. Замеры выполнялись с отключёнными subtree workers и несколькими параллельными процессами; это не надёжный бенчмарк скорости.

Проверены все 15 уникальных плат. Чистых размещений 13/15 до и после; STEPPER_CONTROLLER и ThunderF722 остаются проблемными, новых провалов нет. Состав и заданные фиксированные позиции сохранены везде. Полная длина MST улучшилась на 6 платах, не изменилась на 3, ухудшилась на 6; пересечения линий — 6/5/4, пересечения с падами — 6/4/5 соответственно.

`board-deltas.json` и HTML показывают остальные платы, включая исходно проблемные STEPPER_CONTROLLER и ThunderF722. `measurements.json` содержит показатели всех блоков/модулей и предупреждения, повторно построенные по сохранённому входу. JSON размещений и summary каждого нового запуска сохранены в подпапках. Входы и baseline находятся в соседнем `global-placement-2026-09-27`. Микророутер включён, native binary тот же; менялась локальная сборка в TypeScript и выбор политики родительских блоков. Исправления сохранены в коммите `b898c43`.

Проверки: 160 PCB-тестов, TypeScript typecheck и production build прошли. Новые тесты проверяют обе реальные пары дросселей, исключение D2 из несвязанного острова, связь R6.2 и её диагностическое отображение, предупреждение о подключённом выводе без площадки, включение beam/net candidates для родителя с дочерними блоками. HTML проверен в headless Edge, включая показ скрытой I_OUT.

Повтор из корня backend: Telemetry запускается через `experiment-placement-architecture.mjs` с `PCB_EXPERIMENT_TAG=local-fixes` и режимом `full-micro`; `node scripts/experiment-local-layout-batch.mjs` запускает оставшиеся уникальные сохранённые входы, затем `node --import tsx scripts/experiment-local-layout-report.mjs` строит сравнение. `node --import tsx scripts/diagnose-local-islands.mjs` демонстрирует разницу между выбором острова и минимумом только суммы расстояний до центров.
