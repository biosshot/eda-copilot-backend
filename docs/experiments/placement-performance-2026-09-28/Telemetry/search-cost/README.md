# Стоимость поиска после сокращения гипотез

Изолированный geometric block solver, без board pack и postrefine. Только Current ISO, LTE Power, USB Charge; micro не запускался. Замеры одиночные, с сохранённой базой, а не контролируемый одновременный A/B.

| Блок | Сохранённое время до | После кэша и отсечения |
|---|---:|---:|
| Current ISO (три гипотезы) | 27,89 с | 12,37 с |
| LTE Power | 10,17 с | 4,98 с |
| USB Charge | 9,44 с | 4,37 с |

Все checkpoints (позиции и оценки), включая парные продолжения, совпали с сохранёнными результатами. Для Current ISO используются входы 0, 1, 6 предыдущего восьмигипотезного опыта: исходные группы, разобранные группы и C9=passive. Парное продолжение выбирает существующий selectPairSeeds.

## Принято

- Кэш вклада сигнального отрезка относительно силового компонента. Ключ проверки включает точные координаты отрезка и прямоугольника; быстрый тест габаритов исключает заведомо далёкие отрезки.
- Кэш вкладов препятствий в четыре направления выхода внешнего вывода. Изменение источника, его слоя или позы препятствия инвалидирует соответствующий вклад. Удалены временные массивы прямоугольников в полном проверочном расчёте.
- Во время ранжирования сохраняются верхние границы стоимости глобального списка и каждого пространственного/углового сектора. Кандидат отсекается только когда не может попасть ни в список лучших своего сектора, ни в глобальный список. Равенство оценки не отсекается, порядок при равенстве сохраняется.
- Оценка заканчивается раньше, если сумма уже посчитанных неотрицательных штрафов превышает границу. Неполная оценка не сохраняется как точный score. При трассировке полные списки кандидатов сохраняются.

Current ISO: раньше 1 775 741 обращение к score, включая три пустых начальных состояния. Теперь 927 669 отсекаются по hard rank до score, 848 072 входят в score, а 713 290 непустых состояний доходят до конца оценки. Генератор вызывается 1 308 раз — набор генерируемых позиций сохранён. Время начальной стадии 5,19 с, парной 7,18 с.

## Отклонено

- `pair-trial`: исключение пар без общей неземляной сети и с расстоянием центров больше суммы максимальных габаритов плюс два clearance. Current ISO и LTE совпали с исходными результатами, но USB Charge ухудшился: score 2812,58 → 2900,14 (+3,1%).
- `near-trial`: объединение позиций одного вращения по ячейкам 0,1 мм. Current ISO ухудшился: 11640,26 → 12085,52 (+3,8%); ускорения не получено.

Обе эвристики и их временные переключатели удалены. Их сохранённые результаты нужны только для фиксации эксперимента. В папке `bounded` лежат принятые результаты. В `cache` — промежуточная версия только с кэшами (Current ISO 25,54 с).

Проверки: 10 Rust-тестов block_solver::candidate_tests, включая сохранение разнообразия shortlist при раннем отсечении и инвалидизацию кэша выходов. Для сверки с полными вычислениями используется PCB_NATIVE_VALIDATE_INCREMENTAL_SCORING=1. Сценарий воспроизведения: `node --import tsx scripts/experiment-block-search-cost.mjs current_iso lte_power usb_charge`.

Дополнительно выполнена начальная сборка Current ISO с ролью C9=passive и включённой сверкой каждого кэшированного вклада/нижней границы с полным пересчётом. Сверка прошла, checkpoints совпали. Release-сборка успешна; логи находятся в `logs`.
