## R1 — audit принимает пустые/укороченные массивы графиков

Место: `tests/helpers/pcb-analysis-cross-section-audit.ts:47–48`.

Для S11/S21/crosstalk и каскада с Attenuator Pad проверяется частотная ось, затем вызывается `plot.data.values.forEach(...)`. Проверки `values.length === axis.length` нет. При замене массива на `[]` callback не выполняется, а при удалении последнего элемента проверяется только сохранившийся префикс. Остальные проверки не устанавливают полноту этих данных; `plotArrays` в конце считает объекты series, а не отсчёты. Повреждённый отчёт способен получить `status: "pass"` при пустом/обрезанном графике.

Демонстрационный вход для отрицательной проверки, без изменения solver или оси:

```js
const damaged = structuredClone(validReport);
const plot = damaged.reports.flatMap(r => r.plots)
  .find(p => p.title === "S21 phase");
plot.data.values = [];
// Исправленный auditCrossSection обязан отклонить такой отчёт.
```

Аналогично проверить `values.pop()` и `Line + Attenuator Pad S21 magnitude/phase`. Вывод получен статическим разбором пути проверок; ревьюер не запускал этот тест или solver. Существующий negative test меняет знак одного значения и удаляет объект графика целиком, поэтому этот случай не покрывает.
