# P7 memory and extraction architecture audit

Read-only solver investigation, 2026-10-30. No new candidate run or implementation. Baseline commit 7258677. This report supersedes the claim that far-air coarsening is the primary next optimization for the measured STM32 channel. Exact allocation figures below come from saved logs and source, not a new heap profiler.

## Findings with evidence

1. `src/analyze/board-channel-plan.ts` selects one global X/Y axis by signal-island bounds. It includes all signal branches and all regions intersecting the expanded rectangular bounds; it closes bounds around intersecting plated barrels. Margin is max(0.05 mm, twice board thickness), multiplied by domainScale for the domain. Every transverse edge or non-axis-aligned edge in relevant copper contributes a local interval; intervals expanded by the margin are merged. This is not a path-following multiconductor segmentation. A diagonal uniform trace is classified local over its longitudinal projection. Neighboring plane boundaries/holes can also make locals merge. The existing remote regression asserts every block is local; it retains D5/JP2 branches and a bottom-layer signal segment. Thus ordinary PCB routing can trigger an expensive all-local fallback. The physical necessity of solving every included feature at full order has NOT been demonstrated by sensitivity tests.
2. `volume_magnetic.rs` constructs a scalar Newton-potential stiffness operator with Bernstein basis and reuses its direct factor for vector-component right-hand sides. It is not a full-wave Maxwell solver. A cell touching any copper vertex receives the near-copper degree, not a distance/error-based adaptive degree. Face/edge conformity uses shared entity degree. Coarse default: air3/trace4/interior6; fine: air3/trace6/interior8. Compact: air2/trace4/interior4 or5. This resolves more than just one current value per mesh node.
3. `sparse_potential.rs` private-first AMD plus unrelaxed supernodal LLT stores a large filled factor. Real coarse baseline: n=1,411,442; input upper entries=50,854,985; exact simplicial fill=692,719,663; actual stored panel values=784,635,174. Values alone need 6,277,081,392 B F64. Input CSC payload including pointers is 824,971,304 B. Factor entries/input entries=15.43. The old numerical-stage bound is 8,714,661,076 B, not measured process RSS; factor values account for72.03% of that bound. A dense n-by-n matrix is NOT allocated.
4. Real baseline DOFs: air11,633 (0.82%), near-Cu trace994,048 (70.43%), private405,761 (28.75%). Compact n1,097,762: air2,336, near987,232, private108,194. The tested conforming shell restriction removed zero compact real DOFs. These categories describe basis ownership, not a physical split of the factor or a claim that nearly all material is copper. Mesh:22,614 vertices/112,980 tetrahedra in the compact audit. Scope and high-order trace coverage, not remote air, dominate this case.
5. Saved real F32 run, packet1793379352717185500: original F64 CSC824,971,304 B and converted CSC621,551,364 B coexist. Numeric bound components: base1,029,465,965; converted entry payload610,259,820; symbolic221,742,160; node reserve361,329,152; factor3,138,540,696; scratch632,913,983. Sum5,994,251,776 B. These components are conservative accounting and not disjoint heap-profile samples. Measured process-tree RSS5,992,804,352/private6,433,353,728 B. LLT failed before correction and model construction, not because the8GiB supervisor rejected it. Wall33.71s is failure latency, not calculation speed. F64 input plus F32 conversion is a real temporary duplication (~0.622GB), but does not explain the6.277GB F64 factor.
6. Electric subsystem in that packet:99,215 unknowns,731,650 upper entries,11,388,179 factor values=91,105,432 B; stage bound453,569,699 B. Current subsystem13,292 potentials/99,189 current coordinates; harmonic basis14 voltage/2 current modes. Magnetic factor is therefore much larger than the source/current problem. This contrast is an architectural diagnostic, not proof an alternative basis will be accurate.
7. Exterior enrichment has two n-by9 arrays plus temporary/solve reserves (n*9*24=304,871,472 B at baseline); one n-length F64 vector is11,291,536 B. Magnetic per-job reserve uses n*512 (~722.66MB) plus cell and queried scratch, a bound not an exact allocation. Four independent jobs share factors (parallel.rs), not four copies of the6GB factor; they do own separate residual/RHS scratch. Original CSC remains necessary for compensated residuals. Assembly adjacency and templates are explicitly dropped before factorization. No evidence of an accidentally dense full matrix or copied factor per frequency was found; this is not a complete allocator/leak audit.
8. `board-channel-executor.ts` evaluates domain scales1,2,4 and coarse/fine at each, with2% numerical sensitivity gates; successful domain comparison needs at least two scales/four block solves. It adds three validation frequencies (1000,sqrt(1e7),10000), not every Hz. Factors are reused for RHS within a preparation. Different geometry/domain/degree preparations need new factors. Repeated preparation affects time; the large single factor already dominates peak memory before these refinements finish. Eight-percent total physical error is NOT the same as loosening the linear residual or the2% sensitivity gate.

## 128-line bus

Do not infer128 independent extractions cover crosstalk. Shared cross-section matrices must include off-diagonal mutual terms and finite common return; coupled transitions require multiport locals. Four real128x128 RLGC matrices contain65,536 doubles=524,288 B per section at a frequency. A256-port complex S matrix is1,048,576 B per frequency (~101MiB at101 frequencies). These are output-storage arithmetic only, excluding all extraction and network working storage. The present automatic planner accepts one channel with four contacts and exposes two external ports; there is no demonstrated automatic joint128-line extraction. Existing multiconductor section and network primitives are useful foundations, not proof of readiness. Grouping adjacent lines is valid only with a coupling/error policy, including plane-mediated nonlocal coupling.

## Decision

Do not continue parameter/precision sweeps or call P7 closed. The immediate architectural defect is overly broad all-local fallback, followed by a high-order near-Cu representation solved with a memory-heavy direct factor. Establish route-aligned coupled partitions and an explicit supported-physics envelope; retain the current volume solver for small local/reference problems. If large unavoidable locals still dominate, low-memory iterative or accelerated integral algorithms require reconsidering the previous no-new-solver constraint. Exact runtime/memory savings for these unimplemented alternatives are unknown. No new agent task or numerical implementation was launched in this audit.
