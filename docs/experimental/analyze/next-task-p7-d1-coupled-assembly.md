# P7-D1: сборка совместного EM-канала с обходом разрыва опоры

2026-10-31. Пользователь разрешил следующий этап после ревью B2→C1. Один агент GPT-6.1-sol medium. Родительский план: p7-real-channel-closure-plan.md, первый контроль D. Остальные семейства C (несколько независимых опор, floating, fences) не объявляются завершёнными; они не нужны для выбранного первого случая с одной физически связанной опорой.

## Что принято и что нужно получить

R1/R2 и выбор конечной области исправлены; родитель повторно выполнил 49 tests и typecheck. Исходная STM32 даёт четыре кандидата, один участок 0.25339955 mm с двумя сигнальными координатами и физическим BOTTOM возвратом проходит board adapter. Cold geometry+adapter11.042s, warm adapter3.681s, peak private601235456B; width/air/mesh чувствительность1.1804/1.9640/0.4151%. Это локальная условная PEC-модель, не полный канал, не ошибка относительно независимой физической истины и не экономия whole-STM32 magnetic.

Теперь нужен один действующий путь сборки section+local, который сохраняет совместную электромагнитную задачу через неоднородность. Сравнить с совместным объёмным расчётом той же физической платы, включая магнитную часть. Не заменить работу ещё одним сечением, DC графом или картинкой разбиения.

## Один фиксированный физический контроль

1. Взять существующий малый coupled coupon как основу новой отдельной fixture. Два реальных сигнальных проводника, общий конечный возвратный проводник/плоскость, внутренний разрыв под трассами с реальным медным обходом. Возврат физически связан, но путь меняется; отдельные корпуса/компонентные мосты и via пока не добавлять. Это не должна быть идеальная перемычка по имени GND.
2. Размеры/stack/materials/четыре сигнальных порта с физическими возвратными контактами/нагрузки/полосу записать до результатов. Конечный край опоры должен быть физическим краем исходной fixture, если он используется для расчёта finite-R; нельзя объявлять произвольную боковую обрезку настоящей шириной земли.
3. Заранее зафиксировать непрерывный контроль без щели и основной случай со щелью/обходом. Контроль без щели помогает локализовать ошибку, но его успех не заменяет обязательный случай с обходом. Не менять геометрию после сравнения ради pass; если предоценка делает reference непосильным, выбрать меньшую геометрию до фиксации baseline и объяснить выбор.
4. Общая подтверждённая полоса для первого сравнения — 1–10kHz, с несколькими положительными частотами и независимыми проверочными точками; не менять constants ради MHz. Малый S-отклик в этой полосе не должен скрывать неправильную L: обязательно включить магнитно-чувствительные наблюдаемые, описанные ниже.

## Реализация и последовательность

1. Зафиксировать исполняемые входы обоих представлений. Joint-volume сохраняет всю физику и магнитный solve. Section+local использует уже реализованные совместные сечения, контактное сопоставление и P6. Однородные участки не тетраэдризировать по всей длине; разрыв и обход считать совместно с влияющими сигналами и возвратом. Начать с одного локального блока.
2. Реализовать недостающий внутренний путь сборки для этого случая. Интерфейсы разместить внутри геометрически однородных участков; все проводники/источники/порты сохраняют физическую идентичность. Исходная медь и внешние контакты принадлежат блокам однозначно, без дыр/двойного учёта/исчезновения ветвей.
3. Не включать wide-plane путь в production простым снятием существующего guard. Если текущих портовых координат недостаточно для распределённого интерфейса, явно вывести минимально необходимые дополнительные координаты и реализовать только этот механизм для контрольной геометрии. Если он не выводится в рамках существующей постановки, сохранить конкретный NO-GO с доказательством, не переходить к новым solvers или итеративному перебору эвристик.
4. Finite-R и internal-L: использовать существующий численный путь либо обоснованную и проверенную модель фактического полного проводника. Формула обрезанной произвольной ширины не годится. Нельзя занулить магнитные взаимные члены или потери, чтобы сравнение стало удобным. При PEC промежуточном контроле оба представления должны иметь ту же физику; он не заменяет итоговый finite-conductivity контроль.
5. Сравнить при неизменных портах и нагрузках, затем сдвинуть разрезы внутри тех же однородных участков. Если изменение разрезов заметно меняет результат, не выдавать удачное одно положение за приёмку. Остаточная межблочная связь должна быть учтена либо её влияние ограничено реальной проверкой; отсутствие физического контакта не означает отсутствие поля.
6. Подключить принятый путь к существующему direct DSL и worker/cache там, где текущий контракт это допускает. Реальные joint/segmented multiport comparisons могут использовать внутренний harness, но окончательный channel-run должен действительно исполниться через runAnalysisDsl. Не добавлять новый пользовательский scope/новый solver selector или альтернативный DSL. Если публичного отображения нескольких портов не хватает, назвать точный контрактный blocker, не маскировать internal вызов под полный DSL.

## Численная и физическая приёмка

- Joint reference должен сам пройти существующие mesh/domain/solver guards; невязка solver отдельно от чувствительности. Уточнённый тот же solver — cross-method numerical reference, а не независимое измерение. Сохранить положительные независимые section controls A/C1 и их ограничения.
- Сопоставить полные complex multiport ответы, передачу/отражение и near/far coupling, применимый delay, power/charge conservation и возвратный ток/энергию, если это выдаёт модель. Одинаковые точные ports, orientation, frequency/reference conventions.
- Обязательно магнитно-чувствительное сравнение: например, реактивная часть port Z с правильной для выбранной задачи интерпретацией, магнитная энергия для независимых возбуждений и проекция self/mutual L на те же координаты. Метод и единицы определить до результатов. Не считать Im(Z)/omega чистой L там, где существенна ёмкость, без обоснования. S21≈1 и совпадение DC сопротивления не доказывают магнитную точность.
- Допуск сравнения представлений <=8% при обоснованных заранее floors; <=2% mesh/domain и изменения позиции разрезов. Не переносить допуск8% на каждый блок с обещанием8% целому каналу. Фазы возле нулевой амплитуды/ничтожные наводки оцениваются с явными абсолютными floors, не случайными процентами от нуля. При непроверенной неопределённости reference pass не ставить.
- Отрицательный контроль обязан ловить потерю существенной взаимной связи/ошибочное соединение возвратов. Это может быть намеренно испорченный результат теста, не новая production ветка. Проверить сохранение влияния щели и обхода относительно непрерывного контроля; DC-only negatives недостаточны.
- Все несовместимые/неподдержанные состояния явно в отчёте, без замены на approximate15% без проверки. Не занулять L при отказе magnetic solve.

## Память, скорость, кэш

Профилировать ровно этот совместный и составной контроль: один heavy block одновременно; DOFs, nnz, factor entries/bytes, сокращённые размеры, peak OS tree private/RSS, время подготовки/магнитной части/сборки, cold/warm. Сохранять только нужные reduced outputs/recovery, переиспользовать факторы/кэш, не добавлять второй cache. Подтверждение на малом случае не является доказательством экономии полной STM32.

Рабочий ориентир одной попытки <=300s/2GiB с headroom. Для диагностического joint-reference допустим заранее письменно обоснованный потолок 8GiB/600s из общего плана, но не автоматическое повышение после отказа. Предпочесть действительно малый контроль, не повторять прежнюю полноразмерную STM32. Не запускать unchanged failure, F32/GPU/out-of-core/новую кампанию solvers. Pagefile не менять.
