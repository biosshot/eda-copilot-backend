# Telemetry: единый поиск блоков и восстановление оси U1/U2

«До» — полный прогон из `../full-placement-2026-09-28/Telemetry` (коммит отчёта `8573222`). Вход тот же, SHA-256 проверяется генератором HTML. `geometry/Telemetry` — диагностический полный проход после переключения основного поиска блоков на геометрию, но до исправления финального выравнивания и удаления микророутера из block postrefine. `after/Telemetry` — полный проход с окончательными изменениями. `comparison.html` сравнивает только исходный и окончательный результат; внутри — все 45 блоков и полная плата, ссылки на assembly JSON.

## Причины

Сокращение гипотез ролей в `4b21462` проверялось на geometric, но основная политика всё ещё выбирала micro. Прежняя совместная гипотеза пяти конденсаторов Current ISO перестала генерироваться. При micro победил вариант с длинными связями C9. В geometric оставшаяся гипотеза C9=passive даёт связи 3,50/3,58 мм и сохраняется до финальной платы.

В прежнем полном прогоне U1/U2 выровнялись в обычной упаковке: дополнительная выровненная упаковка была отклонена. После изменения внутренней формы Current ISO обычная упаковка изменилась. Один переход на geometric уменьшил расхождение по X до 5,073 мм, но не устранил его. Новый альтернативный полный вариант отвергался из-за ухудшения обязательных ограничений; эта защита сохранена.

Финальный проход не предлагал нужную общую ось: были только фиксированные доли распределения сдвига, общий поперечный сдвиг обоих блоков и предел 3 мм. Дополнительно любое удлинение отдельной сети более чем на max(0,5 мм, 2%) запрещало шаг независимо от улучшения электрической оценки.

## Изменения

- Основная политика блоков и Rust default используют geometric. Локальный block postrefine также явно использует geometric: подготовка и сравнение Micro-A* в нём не вызываются. Контракт postrefine повышен до 3, чтобы старый бинарник не проигнорировал эту настройку; старые входы версии 2 читаются в прежнем режиме. Явный micro блок-солвера оставлен для воспроизведения старых экспериментов. Упаковщик и postrefine полной платы продолжают использовать свои микророутеры.
- В экспериментальном переключателе исправлен пропуск пакетных вызовов блок-солвера. В отчёт проходят причины выбора упаковки и диагностика подозрительных ролей.
- Финальный проход дополнительно пробует общие оси с шагом не менее 0,5 мм между исходными якорями и независимые поперечные смещения до 1 мм. Общий предел перемещения компонента относительно начала прохода — 4 мм. Старые кандидаты сохранены, веса мягкого выравнивания не повышены.
- Электрическая защита допускает ограниченное перераспределение длин: общий рост не более max(0,5 мм, 0,5%), отдельная сеть не более max(0,5 мм, 25%). Прежняя проверка электрического score сохранена; площадь не участвует в этом разрешении. Обязательные расстояния, зазоры, геометрия, фиксированные позиции и native validation проверяются отдельно. Эти допуски действуют и при выборе полной упаковки, и в финальном выравнивании.

## Проверка

| Показатель | До | После |
|---|---:|---:|
| C9 → U2, I_FILTER_P | 7,246 мм | 3,504 мм |
| C9 → U2, I_FILTER_N | 5,360 мм | 3,579 мм |
| Разница X U1/U2 | 25,246 мм | 0 мм |
| Полный проход | 170,923 с | 182,988 с |
| Общая длина MST | 2277,82 мм | 2165,91 мм |
| Пересечения линий | 254 | 275 |
| Пересечения чужих падов | 284 | 267 |

Оба ядра имеют X=26,375 мм. После удаления микророутера также из block postrefine исходная упаковка изменилась: перед выравниванием разница X составляла 0,934 мм. Финальный шаг сократил общую длину с 2168,27 до 2165,91 мм (−0,109%); электрический score уменьшился с 134348,34 до 134301,55. Нельзя считать результат улучшением каждой сети или каждой метрики. C9 при этом шаге не менялся относительно U2. Полная проверка размещения успешна, состав и фиксированные позиции сохранены. В полном прогоне 65 диагностированных вызовов block postrefine используют geometric. Проверки типов и 38 тестов блоков/выравнивания/postrefine прошли, включая отсутствие Micro-A* jobs при геометрическом postrefine и сохранение микророутера в режиме полной платы. Native release пересобран. Время — одиночные локальные прогоны, не статистический бенчмарк.
