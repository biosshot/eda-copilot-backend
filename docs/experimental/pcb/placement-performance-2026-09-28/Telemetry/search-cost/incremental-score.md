# Инкрементальные вклады в оценку блока

Для каждого вызова генератора неизменная уже размещённая часть теперь готовится один раз. Штраф сигнальных коридоров и штраф длинных двухконтактных сетей для очередного кандидата складываются из вклада этой основы и затронутых новым компонентом взаимодействий. При раннем отсечении добавлен запас на округление `f64`; режим `PCB_NATIVE_VALIDATE_INCREMENTAL_SCORING=1` сверяет каждый результат с полным пересчётом. В горячем цикле также переиспользуется список размещённых примитивов: кандидат переносится в его последний слот и назад без копирования всех уже размещённых примитивов.

Контролируемое чередование режимов на одном release-бинарнике для изолированного Current ISO (geometric; миллисекунды стенового времени):

| Вклады | Прогон 1 | Прогон 2 | Среднее |
|---|---:|---:|---:|
| Старый полный пересчёт обоих | 14 848 | 14 717 | 14 782 |
| Инкрементальный сигнальный коридор | 13 048 | 12 881 | 12 965 |
| Оба инкрементальных вклада | 12 495 | 11 670 | 12 083 |

Снижение среднего времени относительно той же сборки с выключенными вкладами — около 18%. Это одиночные замеры, зависящие от нагрузки машины; дополнительные переключатели использовались только для сравнения и удалены из финального кода.

Финальный код, без профилировщика: Current ISO **11,235 с**, LTE Power **4,703 с**, USB Charge **3,576 с**. Для всех трёх сохранённые checkpoints и итоговые score точно совпали с прежними. Полный пересчёт каждого оценённого состояния всех трёх блоков в проверочном режиме прошёл. Release native build и 10 Rust-тестов block solver прошли.

Испытано также объединение позиций с разбросом до 0,05 мм **после** проверки допустимости и score, при равных жёстких нарушениях и разнице score не более 0,5. На Current ISO оно удалило всего 2107 предложений из примерно 1,77 млн; итоговое качество не изменилось, а дополнительный поиск соседей замедлил прогон. Этот фильтр не принят. Предыдущая грубая дедупликация по ячейкам 0,1 мм ухудшала Current ISO на 3,8%; принимать решение о близости до оценки без проверки качества нельзя.

Оценка блока пока не полностью инкрементальна: оболочка, доступ внешних выводов, пересечения линий с падами и топология путей продолжают рассчитываться для очередного состояния. Изменённые два штрафа дают проверенное ускорение наиболее повторяемой части, но дальнейшая переработка требует отдельного профиля остатка и проверки влияния каждого нового вклада.
