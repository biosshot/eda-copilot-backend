# Инкрементальная оценка блоков

| Блок | До, с | После, с | Сокращение |
|---|---:|---:|---:|
| lte_power | 14.58 | 10.17 | 30.2% |
| usb_charge | 13.15 | 9.44 | 28.2% |
| current_iso | 111.92 | 60.17 | 46.2% |

Только geometric, по шесть потоков на пакет гипотез. До — сохранённые два запуска предыдущего эксперимента (медиана); после — один новый запуск с включённой диагностикой. Это не одновременный контролируемый A/B, фоновая нагрузка не контролировалась. Micro не перезапускался.

Во всех трёх блоках совпали состояния каждого checkpoint и финальные позиции; оценки проверены с допуском 1e-7, hardCount совпал. Генерация, число гипотез и выбранные парные продолжения сохранены. Дополнительно LTE проверен с PCB_NATIVE_VALIDATE_INCREMENTAL_SCORING=1: кешированная оценка сверялась с полным пересчётом на каждом обращении.

Один исходный проход LTE: 213820 полных оценок; общая оценка 4.98 с, внутри неё пересечения падов 3.08 с и длинные связи 0.77 с; генерация 0.53 с, маршрутная добавка geometric 0.095 с. После: тот же проход в пакете имеет общую оценку 2.41 с, пересечения падов 0.85 с. Время вложенных функций нельзя складывать. Название block_micro_route_penalty историческое: здесь эта функция выполняет geometric, не A*.

Изменения: кеш геометрии падов по точной позе; кеш MST сети и её вклада против каждого компонента; инвалидизация при изменении самой сети или чужого препятствия; заранее собранные индексы сетей и метаданные выводов; переиспользуемые буферы; предварительный подсчёт выводов и классификация сетей вместо повторной обработки строк. При неоднозначной принадлежности одинаково названных падов используется полная проверка с общей дедупликацией.

Первый вариант кеша давал слабый/неустойчивый эффект; first-attempt.json и detail-first-attempt.log сохранены отдельно. Итоговая реализация также устраняет повторное создание таблиц сетей и классификацию строк.

Команда PowerShell:

```powershell
$env:PCB_BLOCK_SOLVER_DETAIL='1'
node --import tsx scripts/experiment-incremental-block-score.mjs
```

Целевой Rust-тест инвалидизации кеша прошёл: 1 passed, 0 failed. Release-сборка успешна. Лог теста сохранён в incremental-test.log.

Все изображения совпадают с geometric в [предыдущем отчёте](../isolated-block-metric/comparison.html); повторно не рендерились.
