# Current ISO: сокращение гипотез ролей

Изолированный block solver, geometric, шесть рабочих потоков, сохранённые входы `isolated-block-metric/current_iso-inputs.json.gz`. Micro не запускался. Время включает beam, одиночные и выбранное парное продолжение; не включает postrefine и board pack. Новые времена — один запуск каждого варианта на текущем хосте, сравнение с прежним запуском приблизительное.

| Вариант | Начальный поиск | Парный проход | Всего | Лучший score |
|---|---:|---:|---:|---:|
| Прежние 8 гипотез | 30,50 с | 29,67 с | 60,17 с | 11 640,26 |
| 3 гипотезы, все 5 ролей сразу | 10,95 с | 21,19 с | 32,14 с | 11 845,45 |
| 3 гипотезы, графовая проверка оставила только C9 | 9,93 с | 17,96 с | 27,89 с | 11 640,26 |

Прежние гипотезы: исходные группы; разобранные группы; по одной замене роли C13, C14, C15, C16, C9; совместная замена всех пяти. Простое удаление одиночных проб теряет лучший результат: совместная замена проигрывает пробе только C9 по единой оценке примерно на 1,8%.

Причина ложной подозрительности: C13/C14 подключены параллельно между `I_OUT` и `U2_HDC`, а C15/C16 — между `I_OUT` и `U2_HLDO`. Эти названия не распознаются как питание, но одинаковая пара сетей у двух конденсаторов поддерживает исходную роль `decoupling_cap`. У C9 две отдельные сети `I_FILTER_P` и `I_FILTER_N`, параллельного конденсатора нет. Теперь проверка оставляет C9, а solver запускает одну совместную альтернативу для всех оставшихся подозрительных ролей. Для Current ISO это три гипотезы: группы, разобранные группы, разобранные группы с C9=`passive`.

Состояния всех трёх начальных гипотез и выбранного парного продолжения в последнем запуске точно совпали с соответствующими состояниями предыдущего восьмигипотезного запуска. Входные роли не изменяются; предупреждение сообщает о пробе и выборе результата.
