## Cause and selected correction

The failure is generated by common-partition Boolean intersection/noding, before extrusion or any electric/magnetic solve. Original prepared rings, source identifiers, bores and nominal plating remain unchanged. The old final adapter restricted absolute integer coordinates to2^29. The pinned i_overlay4.0.7 split/cross_solver.rs:209–212 explicitly permits abs coordinates below2^30; its offset differences are widened to i64 and intersection products use UInt128. The historical maximal-safe trial used2^24/mm because it retained the application2^29 bound. It was not a library limit.

The correction selects ONE common dyadic arrangement lattice. Already finer accepted local grids remain unchanged; broader arrangements request at least2^25 units/mm (2.98023223877e-8mm step), bounded by the actual pinned kernel range. A two-integer-unit reserve covers rounded origin/endpoints, and explicit finite/range checks reject unrepresentable extents. This is deterministic coordinate selection before overlay, with no source-specific engines, retry branches, identity special cases or geometry repair. All inherited dyadic points remain exact. Source files/request/guards/dependencies/F64/physics remain unchanged. This minimum precision is an empirically validated geometry representation target for B1, not a proof that every board passes1e-8: original area/topology/contact guards remain authoritative.

Why preserve already fine grids: blanket maximal refinement is not monotonic under repeated integer intersection rounding. The first candidate using2^30 with old0.625 padding still selected2^24 on STM32 and reproduced historical set15 relative1.418278273829372e-8 (no new success). Tight2^30 bounds selected2^25 and admitted the exact whole board, but also changing already fine local lattices caused the existing via coupon set2 area1.073484341e-8 refusal. The final deterministic resolution policy retains those preexisting fine lattices; the unchanged via tests pass again. No guard was weakened and no failed candidate is advertised as accepted.
