## Исправление навязывания пассивности

Правка `native/analyze/src/electrical/vector_fit.rs` (тесты `vector_fit_tests.rs`), измерение на СОХРАНЁННЫХ прямых решениях (новых прогонов решателя нет): `debugging/p7-completion/stage7/7.4/fit-eval-fix.cjs`, результат `fit-result-fix.json`, `fix-eval-table.log`. Те же сетки N=5/8/12, те же 8 отложенных точек, `fitD: true`, `iterations: 30`, `poles: "auto"`, затем то же с `enforcePassivity: true`. Порог 1e-3 не менялся.

Что изменено:
- Метрика возмущения: стоимость изменения элемента ij взвешена на 1/max|H_ij|^2 по точкам подгонки (относительная ошибка, пол 1e-6 от максимального элемента). Минимум взвешенного изменения отклика при линеаризованных ограничениях sigma <= 1 - 1e-6 (S) / lambda >= margin (Y/Z). Малый S11 рядом с S21 около 1 почти не двигается.
- Ограничения: все нарушающие точки сетки (до 150, пики всегда) плюс асимптота D (x -> бесконечность) как отдельная строка; решение по активному набору (начало с пиков, добавляются строки, которые линейный прогноз всё ещё нарушает), демпфирование Левенберга-Марквардта 1e-6, до 40 итераций, шаг после успеха снова растёт.
- Вне диапазона: если нарушает сама асимптота D (в данных D S11 около -1,07, сокращается широким полюсом в диапазоне), а обычное навязывание не достигло цели, один раз перестраивается подгонка с D = 0 и навязывание повторяется (`enforcement.asymptoteRefit`). Проверка сетки не менялась (до 1000 x fmax, плотная сетка и точки полюсов): `passive: true` только когда сетка чиста.
- `poles: "auto"` (+ `maxPoles`): число полюсов только по точкам подгонки; растёт, пока два следующих числа не уменьшают вдвое худший элемент (rms ошибка элемента относительно его пика); предел samples - 2 (минимум 2 уравнения на неизвестное на элемент). С `enforcePassivity` дополнительно навязывается пассивность на числах вниз до половины выбранного, берётся пассивная модель с наименьшей ошибкой худшего элемента на точках подгонки (отложенные не используются). В ответе `poleSelection`.

Метрики: отложенные 8 точек; Zs - последовательный импеданс 2 Z0 (1/S21 - 1). «До» из первого измерения (число полюсов выбрано по отложенным, оптимистично), «после» - `auto`.
