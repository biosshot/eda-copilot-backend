## 1. Где поле берёт узлы XY из сетки тока и как потенциалы меди привязаны к узлам

### 1.1 Откуда XY поля

- `planar_trace.rs:420-426`: `xy` = `board.planar_nodes_mm` (пересчёт в метры от `origin_mm`), `z` = плоскости `board.mesh.nodes_m` (каждая n-я), границы ящика = bbox узлов.
- `planar_trace.rs:484-485`: `planes = vec![0; z.len()]` и единственная сетка `PlaneInput::Exact { source_id: "board-overlay", xy_m: xy, triangles: board.planar_triangles }`. Ни одной отдельной сетки поля нет.
- `layered_capacitance.rs:350-357`: `prepare` принимает `Exact` как есть (или строит CDT для `PlaneInput::Cdt`, строки 358-410; так работает диагностика). Дальше проверки вложенности (строки 415-472: вершины в ящике, замкнутое покрытие, площади).
- `layered_capacitance.rs:1467-1471`: смещения узлов по плоскостям (`offset`), число узлов поля `nodes = n_xy * n_z` при одной сетке на все плоскости.
- `layered_capacitance.rs:1493-1587`: ячейки поля = (слой по z) x (блок наложения треугольника нижней и верхней плоскости). При одной сетке блок = сам треугольник. Принадлежность меди ячейке: `certified.copper[slab * cert.triangles + b.a]` (строка 1513), иначе `relate` блока с полигонами металла (строки 1514-1530). Диэлектрик: `cert.epsilon[...]` (строка 1568) или `relate` с областями подложки (1569-1578).

### 1.2 Как потенциалы меди привязаны к узлам

- Неизвестные потенциалы это координаты смешанной модели. Для фольги: по одной на (медный слой, вершина XY) плюс электродные (`board_foil.rs:419-440`, `:499-500`). Для локального объёма и стволов тоже координаты `potential_map`.
- Привязка к узлам поля: `MixedMap::electric_node_trace` (`mixed_conductor.rs:2806-2809`): для каждого узла 3D-сетки тока строка `weights = [(potential_map[full], 1.0)]`, ширина ровно 1.
- `planar_trace.rs:602-691` (`certified_trace`): ставит на каждый узел поля каждого владельца меди `TraceNode { metal_source_id, position_m, weights }` (строка 688). Сертификат (`CertifiedOverlay`, `layered_capacitance.rs:89-99`) несёт `copper`, `epsilon` по продуктовому треугольнику, `node_owners`, `finite_contacts`, `rowless_modes`.
- В решателе: `supplied` по ключу точных координат (`trace_key`, строки 100-102, 1306), потом `known[n] = Some(metal)` и `trace_weights[n]` (строки 1599-1666). Каждая подставленная трасса обязана быть использована, и каждый узел меди обязан иметь трассу (строки 1609, 1684-1691).
- Условия: веса положительны, сумма 1 (строки 1296-1299): разбиение единицы, общий заряд сохраняется.

### 1.3 Схема редукции (Шур на координаты потенциалов)

Редукция делается неявно, как конденсация Дирихле:

1. Узлы меди (`known`) получают потенциал `phi = sum_j w_j * v_j` (`solve_field`, `layered_capacitance.rs:1071`).
2. Свободные узлы (`active && !known && !far`, строки 1746-1753) решаются разреженным LLT (`faer`, `factorize_symbolic_cholesky` + `factorize_numeric_llt`, строки 1792-1825; `Par::Seq` в строках 1802 и 1819). Правая часть: `rhs -= K[free, known] * phi_known` (строки 1073-1080).
3. Заряд на потенциал `k`: `charge[k] += w * reaction[i]` по узлам меди (`solve_field`, строки 1092-1105; для полной матрицы строки 1864-1869).
4. Это даёт `C_red = P^T * S * P`, где `S` дополнение Шура свободных узлов к узлам меди, `P` матрица весов трассы. Симметрия и неотрицательность следуют из конструкции; решатель к тому же проверяет взаимность 1e-9, баланс заряда, равенство энергии работе, восстановленную энергию (`recover_checked`, строки 2015-2154; в режиме «только действие» часть проверок в `solve_field`).

### 1.4 Что видит гибридный путь

Только действие `SpatialFieldAction` (`layered_capacitance.rs:817-1110`): `apply(v по потенциалам) -> заряды по потенциалам`, `cut_displacement_flux` (поток смещения через охранную коробку), `planned_bytes`, `max_epsilon_r`, `action_count`. Потребитель: `FoilField` (`foil_reduced.rs:60-73`), вызовы `field.apply` в обучении базиса (`foil_reduced.rs:1064, 1254, 2632, 2650`), `field.boundary` (`:3097`). Вызов в гибриде: `mixed_conductor.rs:2193-2208` (строки 2201-2205: `input_from_board` -> `certified_trace` -> `prepare_certified_action`).

## 2. Можно ли подразделить треугольники только для поля, оставив потенциалы на исходных узлах

**Да, по конструкции интерфейса, но с тремя препятствиями в текущей реализации.**

### 2.1 Почему в принципе можно

- Контракт решателя уже «позиция -> веса»: узлы поля, которых нет в сетке тока, получают трассу интерполяцией. Готовая ветка есть в `planar_trace.rs:340-362` (`trace()`, барицентрическая интерполяция по поверхностной грани меди, веса `sum bary_j * w_j`, проверка разбиения единицы строка 363). Комментарий строк 254-255 («CDT-generated vertices... refuse») устарел относительно этой ветки, но показывает, что режим для чужих вершин задуман.
- Прецедент в репозитории: `field_refinement.rs` (путь local-extraction, тетраэдры): узлы поля несут родительское ребро и долю, веса трассы середины = `(1-f)*w_a + f*w_b` (`field_refinement.rs:22-28`, `boundary_split` на строке около 38). Потенциалы остаются на исходных узлах.
- Вторая возможность: `Input.planes` позволяет разные сетки на разных плоскостях (наложение блоков, `overlaps`, `layered_capacitance.rs:573`). Для первого шага не нужна.

### 2.2 Следствие: монотонность

Если мелкая сетка является точным подразделением грубой (все рёбра грубой сетки сохранены, те же плоскости z), то поле грубой сетки допустимо в мелкой, трасса на меди остаётся той же кусочно-линейной функцией. Тогда энергия не растёт: `C_red(мелкая) <= C_red(грубая)` в смысле порядка Лёвнера. Это согласуется с 138 -> 82 пФ/м (грубая сетка даёт верхнюю оценку). Условие вложенности выполняется только если грубые рёбра закреплены ограничениями (иначе триангуляция Делоне может перебросить непринудительные рёбра, и вложенность нарушится). Это проверяемое свойство (тест: `C_грубая - C_мелкая` положительно полуопределена).

### 2.3 Препятствия (что надо менять)

1. **Сертификат требует одну и ту же сетку.** `certified_trace` отказывает, если `triangles != board.planar_triangles` или `xy.len() != n` (`planar_trace.rs:605-608`); массивы `copper`/`epsilon` индексируются продуктовым треугольником `slab * nt + t` (строки 609, 622, 668-674); `extract_impl` отказывает при `b.a != b.b || b.a >= cert.triangles` (`layered_capacitance.rs:1512`). Нужен вариант с картой «мелкий треугольник -> грубый родитель»: медь и диэлектрик наследуются от родителя, `node_owners` нового узла берётся от родителя (узел на ребре: объединение владельцев смежных треугольников), `finite_contacts` не меняется (контакты между слоями определяются по грубым треугольникам, `certified_contacts`, строки 693-697).
2. **Без сертификата точная геометрия не пройдёт.** Некертифицированный путь (`prepare_traced_spatial_action`, `layered_capacitance.rs:1208`) классифицирует каждую ячейку через `relate` с полигоном металла и отказывает `COPPER_TRACE: foil-sidewall cuts cell` (строки 1514-1530), если блок не лежит целиком внутри или снаружи. Коллинеарная вершина Штейнера на ребре произвольного наклона в float лежит на ребре с точностью до ulp, поэтому `is_within` может дать ложный отказ. (Гипотеза, не проверено; в диагностике этого не было, там все рёбра осевые.) Плюс стоимость: relate по ячейкам x металлам. Значит, нужен именно сертифицированный путь с наследованием.
3. **Интерполяция в `trace()` ищет только поверхностные грани меди** (`copper_interfaces`, `planar_trace.rs:342-361`; это грани «медь-диэлектрик», `mesh.rs:418-428`). Новый узел в средней плоскости фольги (`P7_FOIL_SHEET`, плоскости `t/2`) на такую грань не попадает и даёт `PLANAR_TRACE: field node outside physical conductor surface` (строка 361). Для вложенного измельчения проще и точнее: запоминать родителя (треугольник или ребро грубой сетки в той же плоскости z) и считать веса барицентрически по грубому треугольнику той же плоскости, без поиска (O(1), без R-дерева).

## 3. Правило измельчения и оценка числа узлов поля

### 3.1 Правило (предложение, не проверено)

Измельчать только в XY, сохраняя все узлы и рёбра грубой сетки (вложенность, раздел 2.2). Плоскости z пока не трогать (отдельный рычаг, см. 3.4).

1. **Рёбра меди** (главный вклад: 94% избытка по 4.1.3ж). Вдоль каждого ребра контура меди вставлять узлы и строить пояса на расстояниях `d_k = (h_d/4) * 2^k`, `k = 0..K`, где `h_d` локальная толщина диэлектрика между слоями (для купона 100 мкм, первый шаг 25 мкм, как в уровне 2), пока `d_K` не достигнет примерно `4*h_d` или размера дальней зоны. Для купона уровни 2-3 соответствуют первому шагу 25 / 12,5 мкм по y (по x у торцов 50 / 25 мкм).
2. **Вдоль ребра шаг анизотропный.** В диагностике шаг вдоль длинных прямых рёбер был до 3-4 мм (линии по x только у торцов, `graded_lines`, `layered_spatial_tests.rs:170-190`, `8 * max_step`) и уровень 2 всё равно сошёлся в 4% от 2D. Поэтому вдоль прямых рёбер шаг брать порядка шага грубой сетки (0,5-1 мм), поперёк по поясам. У концов, углов и на дугах измельчать в обоих направлениях (угловое сгущение).
3. **Зазоры между медью одного слоя:** не менее 3 ячеек поперёк зазора (`g/4`); пояса от двух рёбер сливаются.
4. **Рядом с возвратом.** Над сплошным полем возврата внутренние ячейки можно оставлять крупными (поле почти однородно, это плоский конденсатор). Измельчать рёбра (трасса, край возврата), а не внутренность перекрытия.
5. **Дальняя зона** (дальше `4*h_d` от рёбер) без изменений.
6. **Ограничение области** (снижение цены, вторая ступень): применять правило только к меди каналов и в радиусе 1-2 мм от неё. Готовая машина выбора опоры есть: `mesh_coarsen::SizeField::new(support, ...)` и `mesh_coarsen::grade` (`board_mesh.rs:1098-1111`, `mesh_coarsen.rs:35, 82`; опора = электроды портов, медь каналов, их стволы). Сейчас на TPS она выключена (`d0: null`, лог `P7_MESH_COARSEN`).
7. **Точки Штейнера** на ограничивающих рёбрах ставить по построению через ограничения и запоминать родителя (ребро, доля) для весов трассы.

## 4. Время и память решения поля на плате

### 4.1 Тип решателя

Разреженный LLT Холецкого (`faer`, `layered_capacitance.rs:1792-1825`), последовательный (`Par::Seq`), порядок по умолчанию `Default::default()`. Для тонкого пакета (несколько плоскостей z, широкая плоскость XY) сложность факторизации между `O(N^1.5)` (2D-подобная структура) и `O(N^2)` (3D), память факторов от `O(N log N)` до `O(N^{4/3})`. Дополнительно: одно действие `apply` это два треугольных прохода по `nnz(L)` (`solve_field`, 1060-1110); их число на плату несколько десятков (в прогоне TPS `chargeActions=40`, плюс вызовы внутри обогащения `foil_reduced.rs:2632, 2650`, и два решения на каждый вызов `boundary`).

## 5. Критерий приёмки и что ещё проверить

### 5.1 Главный критерий

C купона 3D при XY-измельчении против 2D секции 79,2 пФ/м: допуск 5%, то есть диапазон [75,2; 83,2]. Измерять так же, как в 4.1.3д: через ABCD из S для длин 10 и 5 мм на 100 МГц, и параллельно диагностикой поля (C11 по разности длин). Для сравнения по задержке: при L 3D выше 2D на 4% и C в пределах 5% ожидаемая задержка порядка 6,1-6,2 пс/мм против 5,91 у 2D (расчёт sqrt(1,042 * 1,05), ориентир, не критерий).

Предварительные данные диагностики 4.1.3ж (25 мкм по z): уровень 2 даёт 82,4 (+4,0%, проходит с малым запасом), уровень 3 даёт 81,7 (+3,2%), уровень 1 даёт 84,5 (+6,7%, не проходит). С 10 мкм по z уровень 3 даёт 80,6 (+1,8%). Вывод: по числам уровень 2 это минимум, уровень 3 даёт запас. Остаток около 1,2 пФ/м не объяснён (гипотезы 4.1.3ж, раздел 4).

Сопоставление «как с как»: 2D секция без коробки; 3D с заземлённой коробкой добавляет к C11 около 0,4 пФ/м (0,5%) при εr = 4 и около 0,8 пФ/м (3%) при εr = 1 (4.1.3ж, раздел 1). Для вакуумной проверки сравнивать с 2D с рамкой (27,87 при 2 мм) или сеткой «без коробки» (27,41 для уровня 3 при 10 мкм), иначе 5% не набирается.

### 5.2 Что проверить дополнительно

1. **Паритет при выключенном переключателе.** Без включения: S, C-матрица, `plannedBytes`, число узлов и порядок мод совпадают побитно с HEAD (как делали шаги stage0/stage05 «off»). Отдельно проверить, что ключ кэша различает включённый и выключенный режим.
2. **Монотонность и вложенность.** `C_red(мелкая) <= C_red(грубая)` в смысле Лёвнера (разность положительно полуопределена); при нарушении это признак невложенной триангуляции (раздел 2.2) или ошибки весов.
3. **Сходимость.** Уровень k против k+1: изменение C11 меньше 2% (по купону 2 -> 3: 0,8%); на плате изменение C ёмкостей каналов (диагональ `C_red` портовых потенциалов) между двумя уровнями меньше 2-3%.
4. **Пассивность и физические инварианты.** Внутренние проверки решателя (взаимность 1e-9, баланс заряда, работа равна энергии, невязка свободных строк 1e-8) остаются зелёными; `C_red` симметрична и неотрицательна (минимальное собственное значение не меньше нуля с допуском); S проходит `powerBalanceErrorW` и пассивность `||S|| <= 1` на всех частотах диапазона; коэффициент взаимности S12 = S21.
5. **Сдвиг S платы.** Платы TPS63060DSCR (band-step 100 кГц, 1, 10, 40 МГц), NanoScope, BandAmpV5, STM32G0_CAN_RS485, ThunderF722: сдвиг |S21| и фазы до и после, сопоставление с 4.1.3д (уменьшение C должно уменьшить задержку и сдвинуть резонансы вверх); для 1 МГц и 700 кГц проверить, что stall KVL и неопределённость не ухудшились (4.1.0g, 3b).
6. **Каскад.** Каскад 4.1.3г пересчитать (его принятые пороги опираются на старое C).
7. **Ресурсы.** Время и пик памяти на TPS: поле не более 20% лимита (при 4096 МиБ это около 0,8 ГиБ), сумма пика не выше 4096 МиБ; фиксировать `plannedBytes`, число узлов поля и `free_nodes` в evidence.
8. **Стволы.** Контрольный купон и плата с переходными отверстиями: C около отверстий не меняется (измельчение не затрагивает локальный объём), разница фиксируется как остаточная.

### 5.3 Порядок работ (предложение)

1. Дешёвая диагностика: `CAP_LEVEL=2 CAP_IFC_UM=0` (раздел 3.4), без изменения кода.
2. Прототип на купоне: вложенное подразделение + веса от родителя + карта «мелкий -> грубый» в сертификате; сверка с диагностикой уровня 2 и с паритетом при выключенном переключателе.
3. Один прогон TPS (4 ядра, одно задание) с ограничением области (правило 6), запись узлов/времени/памяти; сравнение с таблицей 4.3.
4. Расширение области и/или `interfaceStepM`, если шаг 3 даёт запас по памяти.
