# P6: приёмка ограниченного расширения электрического ядра

2026-10-24. Проверка родительским агентом после реализации в `analyze-p6-completion`.

Принимаются explicit AC V/I/transfer, простые источники и нагрузки, полный R/L/C
descriptor, ограниченное пассивное sampled-RC → time приближение и точные
real-K delay модели. Это проверяемое расширение P6a/P6b; полный исходный P6,
PCB PI и SI этим документом не объявляются закрытыми.

## Что проверено

- Прочитаны адаптация моделей/схем/временных возбуждений, сохранение свойств
  частотных ресурсов, общий descriptor и временной расчёт, независимый аудит.
- Устранены замечания о проверке `analyses` по текущей операции и едином сроке
  fit → composition → assembly → time. Дополнительно исполнитель исправил
  разрастание истории validity при повторном соединении вычисленных ресурсов.
- Независимо сверены все **226** хешей `final-review-manifest.json`:
  исходники для ревью, compiled/installed файлы и сохранённые результаты.
  Несовпадений нет; хеш штатного addon также совпадает.
- Рассмотрены 37/37 финальных native gates, перенос прежнего strict RL/RLC
  случая через release addon (4/4 без изменения 120 s), typecheck/build,
  проверки установленного пакета, отмены/таймаута/восстановления,
  прямые DSL-сценарии и отрицательные проверки сохранённых результатов.
  Неизменные дорогие расчёты повторно не запускались.
- Просмотрен итоговый PNG STM32G0_CAN_RS485: AC, независимый RC reference,
  временное уточнение, отражения, задержка и все четыре параметра каскада.
  Подпись явно отличает авторские модели в контексте платы от извлечения PCB.
  Два остальных PNG проверены исполнителем. HTML controls не проверены.
- `git diff --check` не выявил ошибок whitespace.

## Оставшаяся граница

Матрица в [verification](electrical-core-completion-verification.md) остаётся
обязательной. В частности, смешанные delay/RLC/relaxation соединения,
произвольное соединение infinity-reference моделей и общий resonant/active
sampled fitting пока отсутствуют. Нельзя молча заменить их common return,
продолжить частотную таблицу вне полосы или назвать RC-fit универсальным.

Следующий шаг по P6 — выделить необходимые для P7/P8/P11 соединения в отдельное
проверяемое продолжение; не переходить к полному PI/SI на основании одной этой
приёмки. P7 отдельно доказывает геометрическую и физическую точность извлечения.

Подробные команды, сохранённые неудачные попытки, эталоны и ограничения:
[verification](electrical-core-completion-verification.md),
[semantics](../reference/electrical-core-completion-semantics.md).
