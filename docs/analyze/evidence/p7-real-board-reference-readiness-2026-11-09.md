# Готовность эталонов для пяти плат P7

Сверка входов на 2026-11-09. Проверены порты в [пяти DSL](../../../tests/fixtures/analysis-p7-closure) и назначение сетей в соответствующих PCB JSON из [очереди](../reference/p7-extraction/p7-hybrid-final-queue.json). Все текущие DSL выполняют двухпортовый расчёт на трёх частотах от 1 до 10 кГц с предполагаемым стеком, медью 58 МСм/м и диэлектриком εr = 4,2 без потерь. Эти гипотезы подходят для сравнения численных моделей на одинаковом входе. Для сравнения с изготовленным образцом нужны фактические стек, толщина фольги и металлизации, параметры диэлектрика и условия подключения.

| Плата | Существующий одиночный канал (сигнал / возврат) | Следующий вход с взаимной связью | Эталон для приёмки |
|---|---|---|---|
| STM32G0_CAN_RS485 | RS485_B, U5.7 / U5.5 → J5.2 / J5.3 | Добавить RS485_A, U5.6 / U5.5 → J5.1 / J5.3. Сохранить все ответвления, переходы и общую опору. | Независимый расчёт конечной геометрии или измеренный четырёхпортовый отклик. Сравнивать собственные и взаимные Z/Y, mixed-mode преобразование и потери. |
| NanoScope | QSPI_SCLK, U3.52 / U3.57 → U4.6 / U4.4 | Добавить QSPI_SD0, U3.53 / U3.57 → U4.5 / U4.4. Для отдельного PDN входа подходят порты питания U3.1 / U3.57 и U4.8 / U4.4. | Для пары сравнивать собственные и взаимные члены и NEXT/FEXT. Для PDN нужен отдельный независимый Z-matrix по портам питания с зафиксированными состояниями развязки. |
| ThunderF722 | SPI2_SCK, U2.34 / U2.31 → U4.6 / U4.4 | Добавить SPI2_SDI, U2.36 / U2.31 → U4.5 / U4.4. Наблюдение вести при возбуждении каждого канала по очереди. | Независимый четырёхпортовый расчёт или измерение, включающее все шесть слоёв, переходы и связи через общую опору. |
| TPS63060DSCR | VIN, J1.1 / J1.2 → U1.3 / U1.4 | Для bare-board PDN добавить C1.1 / C1.2 и C2.1 / C2.2 к двум существующим портам VIN. VOUT образует отдельный домен и требует явной модели компонентов для приёмки собранной платы. | Для DC измерить или независимо рассчитать матрицу сопротивлений. Для AC сравнивать Zii/Zij, резонансы и влияние развязки на согласованных частотах. |
| BandAmpV5 | RF_IN_PORT, RF1.2 / RF1.1 → C1.1 / U1.2 | Для входного пассивного канала задать RF-полосу и плоскости калибровки RF1 и C1. Проверить опору у C1. Для собранного усилителя нужны состояния C1 и активного элемента. | Двухпортовое VNA измерение с исключением оснастки или независимый полноразмерный 3D расчёт пассивной геометрии. Сравнивать комплексные S, IL/RL и фазовую задержку. |

Пары выше подтверждены по сетям контактных площадок. Геометрический overlap и пригодность выбранных возвратных контактов ещё требуют проверки. Все варианты сохраняют исходные платы и должны оформляться отдельными входами. Частотную полосу для цифровых пар определяют модели фронтов и условия нагрузки. Для PDN и RF полосу фиксируют по требованиям сценария до сравнения.

Найденный `stm32-joint-reference-request.json` задаёт запрос на локальный расчёт CAN_L/GND, а текущий вход U5→J5 использует RS485_B/GND. Его численные контроли полезны для баррелей и локальных полей, но эталон для U5→J5 остаётся открытым. Имеющийся Touchstone `attenuator-pad.s2p` относится к тесту частотной сети. В манифесте приёмки для всех пяти плат поле эталона остаётся пустым. Сопоставимых независимых результатов по этим портам, полосам и условиям в проверенных артефактах не найдено.

## Аналитические контроли сопротивления прямых участков

Из PCB JSON взят самый длинный двухточечный отрезок каждой сети одиночного канала. Для прямоугольного медного проводника с полным контактом на обоих торцах и изолированными боковыми гранями точное сопротивление постоянному току равно `L / (σ·w·t)`. Использованы σ = 58 МСм/м и t = 35 мкм, как во входных DSL.

| Плата | ID дорожки | Длина, мм | Ширина, мм | Сопротивление, мОм |
|---|---|---:|---:|---:|
| STM32G0_CAN_RS485 | `43e27db2346a5269` | 3,220100 | 0,2540 | 6,245103 |
| NanoScope | `e43559` | 9,283244 | 0,2000 | 22,865134 |
| ThunderF722 | `e374` | 1,724600 | 0,2540 | 3,344711 |
| TPS63060DSCR | `0aed73aa4f8ed7ba` | 3,645843 | 0,7500 | 2,394642 |
| BandAmpV5 | `dcc17162579803b7` | 10,629900 | 0,6736 | 7,773759 |

Контроли задают целевые значения для отдельных прямоугольных образцов с размерами с реальных плат. При сравнении с полным каналом необходимы также сопротивление возврата, контакты и распределение тока по параллельным путям. Для взаимных связей и AC остаются отдельные эталоны.

Перед присвоением статуса следует сохранить хэши платы и DSL, независимую геометрию и версии инструментов, карту портов и полярностей, схему возбуждения и завершений, частотные точки, абсолютные пороги слабых членов и оценку погрешности эталона. Для расчётного эталона необходимы отдельные проверки сходимости сетки и размера области. Успешный запуск на предполагаемом стеке фиксирует исполнение и ресурсы для этой постановки. Физическая приёмка каждой платы остаётся открытой до независимого сравнения.
