## Internal schema agreed with route-partition

`board_mesh::Request.domainPolygonMm?: [number,number][]` accepts a valid simple polygon; `roiMm` retains bounds. Rectangles remain supported. `cutPlanes` accepts legacy `{axis, atMm, spanMm?: [min,max]}` or `{originMm: [x,y], normalXY: [nx,ny], spanMm?: [min,max]}`. Normal is a finite unit vector. Oriented spans project relative to origin on tangent `[-ny,nx]`. Legacy axis spans retain increasing coordinate semantics.

R1 electrodes specify exactly one `sourcePath: string` or `sourcePaths: string[]`, plus existing name/layer/upper. Both canonicalize to sorted unique source paths in native physical signatures and certified descriptor comparison. Every source must exist on the specified layer. Every member of a multi-source union must contribute to the finite contact. Connected multi-source cut intervals are accepted; disconnected intervals are explicitly refused with a split-contact diagnostic. The TS owner must emit distinct electrodes. Multi-source horizontal faces require one connected polygon. Existing current-space validation also rejects electrodes bridging disconnected copper volumes. No net-based union or representative-source substitution.

## Physical implementation

Polygon domains and physical copper use the existing dyadic Boolean overlay. A coarse crop strictly outside the domain bounds sources before finer local clipping. Polygon-domain material unions use clipped original source polygons on the local grid, avoiding unattributed slivers from a separately rounded global layer union. Rectangular material requests preserve their original path.

Contacts use canonical domain edges, physical source ownership and one-dimensional finite intervals. Rotated face-centroid arithmetic is not tested by exact coordinate equality. No nodes or components are joined by proximity/net name. The original 1e-8 arrangement copper-area/topology and contact-area guards remain unchanged. Actual bores, foil spans and complete through barrels stay in the common geometry; cuts through plated barrels remain rejected.

R1 unions are actual polygon unions (overlaps counted once), and their certified nodes enter the existing current-space electrode quotient. Finite span clipping uses bounded domain projections on the existing local grid; this also fixes an out-of-adapter panic exposed by a rotated-span regression. No public DSL or physics solver change.
