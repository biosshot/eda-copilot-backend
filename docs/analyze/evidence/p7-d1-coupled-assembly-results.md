## Minimal remaining mechanism and decision

This bounded control does **not** establish a validated joint reference, finite-conductivity section coefficients, or a cut-invariant hybrid. Its failure is not fixed by the matched-wave transport correction, a common GND name, P6 conservation, a successful straight S/DC check or an added plane energy stamp.

The current interface transmits one equipotential and integrated longitudinal current per conductor face. For an asymmetric return bypass, equal total current does not determine its transverse profile. A minimal extra trace coordinate would include the first transverse moment M=integral(xi*J_normal)dS with dual potential coefficient V1 in V=V0+V1*xi, so interface work is V0*I+V1*M. A scalar weld supplies only V0/I. Even that extra moment alone does not recover external inter-block field energy: global Wm contains self energies plus integral(mu*H_A dot H_B)dV, while composition receives block-diagonal supplied L and no shared field trace/operator. Physical joining can redistribute currents but cannot infer those missing energy terms from the resource matrices. No calibrated subtraction-free cross-field/trace operator or compatible conservative current projection is provided by the present scalar interface.

The continuous15.28% disagreement, slot11.04%, cut3.78%, unresolved joint10.2% magnetic profile and recovered-flux discrepancy prevent selecting one empirical correction. A validated shared current/field trace and compatible magnetic energy ownership must first be derived against a converged reference, including the low-band ribbon-current profile; adding global plane L/C would double-count existing self storage. This is a concrete NO-GO for the present D1 representation, not a proof that hybrid extraction is impossible in general. No new solver campaign, geometry tuning, bound relaxation, profile3, F32/GPU or global plane correction was attempted.
