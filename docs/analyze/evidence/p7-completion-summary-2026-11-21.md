## Что дали этапы

- 1: бюджет памяти запроса доходит до экстрактора и пути DC (STM32G0 больше не падает за 4 с).
- 3: многопортовое обогащение сходится на шине TPS; разбиение полос pi(); DC по всей меди. M1 по всей сетке — `complete`.
- 2, 6: модель пары плоскостей сверена с аналитикой, но против гибрида только на 10 МГц (по R на низкой частоте расхождение 6,9 раза); критерий «делать» не заработан, этап 6 не выполнялся, в продукт она не введена.
- 4: каскад каналов в DSL за `P7_CHANNEL_CASCADE` (прямая цепь на одном слое); M5/M6 — названные отказы со структурой канала.
- 5: откалиброванная оценка памяти области; вся плата вместо коридора там, где помещается.
- 7: повторное использование H-матрицы между полосами; vector fitting с проверкой пассивности; рациональная развёртка оси `impedance()` с откатом на прямой расчёт.
- 8: многотельный блок возврата не нужен ни одному каналу; закрыт без кода.
- 9: DC → тепло на плате через `a.dc().idleNets([...])`; нулевые источники тепла не передаются решателю.

## Ограничения для P8–P12

- P8 (PI): pi() на полной сетке укладывается в 3600 с только на TPS; на STM32G0 и BandAmp — одна точка за 8–12 мин, полная сетка — отказ по сроку. Политика аудита pi() (11 решений на полосу: 3 опорных + 8 проверочных) и срок — решение пользователя.
- P10: однонаправленная передача DC-потерь в тепло готова (`conditional`); электротепловая связь R(T) на плате не реализована.
- P11 (SI): модель канала до 1 ГГц — только каскадом и только для прямой цепи на одном слое без переходов (BandAmp RF_IN/RF_OUT). Каналы с переходами слоя (M5), связанные пары (M6) — отказ выше 26–40 МГц.
- P12 (EMI): связь SW → FB на TPS (M8) — отказ по току возврата; ВЧ-модели связи на плате нет.
- Рациональная модель (этап 7) для временной области не используется — решение пользователя.

## 10.5. Предложение по умолчаниям

`P7_CHANNEL_CASCADE` — единственный переключатель нового представления, оставшийся выключенным. Довод включить по умолчанию: M7a/M7b с ним `complete`, без него — отказ; при неприменимости каскада канал идёт прежним путём (причина пишется в ошибку); без переключателя паритет побитовый (этапы 4.4–4.6). Против: физика `unverified`, стыки идеальные (оценка `|dS11| <= 0,01` на верхней частоте). Решение за пользователем. Остальное из P7-completion уже включено без переключателей (7.2, 7.5, 9) или задаётся в запросе (`enforcePassivity`, `poles:"auto"`, `idleNets`).
