2026-11-09. Код `49d3187`, native core identity `84a2a349addbeec40aedd2c53cb3ab1aea11d164ec004de7eab4e99cfa5ef103`. Все пять исходных DSL из финальной очереди отклонены с `LOCAL_INPUT: Contact layer required` до численного расчёта. Хэши исходных входов проверены штатным runner. При повторе плата, стек, материалы, порты и диапазон 1–10 кГц сохранены. В локальной копии DSL заданы слои электродов `TOP` по площадкам и стороне монтажа, бюджет в DSL увеличен до 590 с / 10240 МиБ. ## Синтетический контроль

Свежий холодный расчёт явного coupled stripline прошёл TEM-сравнение при 1, 10 и 100 МГц. Wall 5.453 с, peak RSS 924.8 МиБ, peak private commit 940.5 МиБ. Тот же результат отдельно сравнили с независимым конечно-разностным эталоном штатными формулами baseline. Максимальная ошибка по C/L, модальным Z и задержке и комплексным четырёхпортовым S составила 0.07053%; с учётом 2% неопределённости эталона сравнение укладывается в 8%. Пакеты `stripline/` и `stripline-fd-comparison/`. Это явный купон, автоматический выбор и взаимное влияние дорожек на реальной плате остаются открыты.

Повтор диагностики из корня backend с чистым путём вывода:

```powershell
$packet = 'debugging/p7-acceptance-20261109-123649'
$board = 'STM32G0_CAN_RS485'
$env:P7_SUPERVISED_BOARD = '1'
$env:P7_COMPACT_PLANAR = '1'
$env:P7_SUPERVISOR_TEST_TIMEOUT = '600'
$env:P7_VERIFY_SECONDS = '600'
$env:P7_VERIFY_MEMORY_MIB = '10240'
$env:P7_SUPERVISOR_OUTPUT = Join-Path (Get-Location) "$packet/replay/$board"
$env:P7_SUPERVISOR_TEST_COMMAND = ConvertTo-Json -Compress -InputObject @(
  'node', '--import', 'tsx', "$packet/runner.mts", $board
)
python scripts/verify-p7-closure-supervised.py --memory-mib 10240
```

Для проверки двух дорожек используется `runner-mutual.mts` и суффикс `-mutual` у идентификатора платы.

## Две связанные дорожки на реальной плате

Групповые четырёхпортовые сценарии прошли привязку четырёх портов после добавления обязательных привязок приёмников в локальные копии DSL. Использован тестовый стимул 1 кбит/с с фронтом и спадом 100 мкс. Во всех трёх численных прогонах воспроизвёлся блокер одиночного канала. Supervisor не прерывал эти прогоны.

| Плата и пара | Wall, с | Peak RSS, МиБ | Peak private commit, МиБ | Причина остановки |
|---|---:|---:|---:|---|
| STM32G0_CAN_RS485, RS485_B / RS485_A | 6.828 | 195.8 | 231.8 | `LOCAL_BOARD_ARRANGEMENT`, set5 |
| NanoScope, QSPI_SCK / QSPI_SD0 | 59.828 | 317.0 | 283.1 | `LOCAL_BOARD_PADSTACK` |
| ThunderF722, SPI2_SCK / SPI2_SDI | 25.093 | 255.8 | 219.9 | `LOCAL_BOARD_PADSTACK` |

Пакет `mutual-retry/`. Взаимные параметры на реальных платах не получены. Независимые аналитические DC-эталоны для пяти изолированных прямоугольных участков и границы их применимости приведены в отдельной сводке по эталонам. Сопоставление с полными каналами по этим эталонам неприменимо.
