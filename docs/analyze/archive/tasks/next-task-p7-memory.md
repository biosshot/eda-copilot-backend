# P7: память текущего direct-FEM, 2026-10-30

Утверждено пользователем: главный приоритет — уменьшить RAM и время; допустимо до 8% расхождения выбранных физических наблюдаемых с эталоном. Старое расхождение композиции 7,79% остаётся отдельной известной проблемой; автоматически P7 не закрывать. Невязки, KCL/KVL, взаимность, пассивность и физические контакты не ослаблять.

Сохранить CPU/F64 и direct sparse FEM. Без out-of-core, нового iterative solver, GPU, внешних solver dependencies. Допускается простая явно выбранная подкачка средствами ОС с лимитом commit и возможностью отмены; настройки файла подкачки ОС автоматически не менять. Не занулять магнитную физику.

Основная работа: ограниченный эксперимент снижения порядка магнитных функций/числа неизвестных при неизменных геометрии, контактах и материалах. Сначала измерить baseline и до двух более дешёвых профилей на существующих небольших эталонах, оценить физическую ошибку (порты, L/энергия, задержка, потери), затем один лучший на реальном remote STM32. Сохранить старый профиль для регрессий, не размножать production ветки. Кэш обязан учитывать выбранный численный профиль. Нельзя принимать только DC R как подтверждение магнитной точности.

Параллельный независимый аудит: из чего складывается numeric-factor plan (CSC, символика, values, scratch, retained); сравнить символические варианты порядка/хранения без тяжёлого выделения фактора, если возможно простым кодом. Изменения физики/solver запрещены. Устранение подтверждённых копий допустимо при сохранении результата.

Тяжёлые сборки и расчёты — последовательно, один владелец. Профиль времени/фактический RSS и оценки памяти различать. До запуска проверять доступную память; не запускать заведомо непомещающийся 8,7GB фактор на малой RAM. Использовать уже сохранённые references, не повторять без причины. Не трогать пользовательский native/analyze/debugging. Focused tests, native build при Rust-изменениях, typecheck/build при TS. Обновить CHANGELOG и единый отчёт p7-memory-results.md, с честными ограничениями и сравнениями. Коммиты после ревью родителя; агентам не коммитить общий tree.
