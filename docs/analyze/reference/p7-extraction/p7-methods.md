# P7: методы по классам (предварительно)

Статус: **черновик перед реализацией**. Это не приёмка и не спецификация кода — таблица того,
что придётся строить, менять и проверять. Уточняется при реализации.

Общая схема у всех классов одна: **2D-сечения на однородных участках + 3D-блоки на
неоднородностях + сборка через P6**.

## Сводная таблица

| Класс | Что делаем | Что строим | Проверки | Чего нет сейчас |
|---|---|---|---|---|
| **Split** (разрыв опоры) | Разрыв и обход — событие; участки до/после — 2D | Локальный 3D-блок; окно обязательно включает обход | Сдвиг разреза 2%, домен 2%, баланс возвратного тока, сравнение с/без разрыва | Планировщик не строит «split event», corridor отказывает |
| **Multi-ref** (несколько опор) | Каждая опора — отдельный проводник; объединять только после теста | 2D-сечение с N опорами + матрица соединений; локальный блок с несколькими reference | «Две опоры против одной» ≤2%, сопротивление соединения | 2D-сечение поддерживает одну опору |
| **Ref-swap** (смена опоры) | Каждый переход — событие: signal via + return via/соединение | Локальный 3D-блок на переход + 2D между | Соединение найдено; гейты события; нет weld по имени | Планировщик не детектит смену; лимит 8 не реализован |
| **Blind via** | Ствол только между своими слоями | Локальный 3D-блок: barrel в своём span, padstack, antipad/stub | DC-непрерывность, R ствола, stub, путь возврата | Нужна проверка/доработка partial-span в `board_mesh` |
| **Diff pair** | Два сигнала + возвраты, 4 порта | Явное coupled-сечение + 4-портовый локальный блок | 4-port S, mixed-mode, skew, crosstalk, непрерывность опоры | Планировщик принимает один `from/to`, а не группу |

Ключевое: **новый solver не нужен ни для одного класса**. Нужны планировщик, расширение
2D-сечения на несколько опор, модели соединений и приёмочные кейсы.

## Split

- Событие: сам разрыв плюс физический обход возврата.
- В окно обязан входить обход; если он далеко — расширять окно или строить распределённую
  модель плоскости.
- Проверки: сдвиг разреза, домен, баланс возвратного тока, сравнение с/без разрыва.
- Дешёвый класс: планировщик + существующий local 3D.

## Multi-ref

- Два уровня: 2D-сечение с N опорами и локальный блок с несколькими reference.
- Объединение опор — только после теста «две против одной» (≤2%) и проверки сопротивления
  соединения.
- Имена GND/AGND/PGND не соединяют.
- Самый дорогой класс: нужна математика 2D-сечения с несколькими опорами.

## Ref-swap

- Каждый переход — отдельное событие, а не section.
- Найти физическое соединение; если его нет — отказ.
- v1: до 8 переходов на канал; больше — отказ с сообщением.
- Случаи: тот же net с обходом; AGND→GND через звезду; смена слоя; ёмкостный возврат;
  переход без найденного соединения.

## Blind via

- Ствол соединяет только свои слои; antipad и stub учитываются.
- Нужны partial-span в геометрии/сетке, padstack и отдельные кейсы signal/return via.
- Проверки: DC-непрерывность, R ствола, влияние stub, путь возврата.

## Diff pair

- Явное coupled-сечение уже работает; автоматический путь — расширение планировщика.
- Нужны: группа сигналов (2 дорожки + возвраты), 4-портовый локальный блок, mixed-mode S,
  skew и crosstalk.
- Проверка непрерывности опоры для обоих проводников.
