# P7: матрица случаев

Ускорение и ограничение области выполняются по [плану ускорения P7](../../plans/p7-acceleration-plan.md). Все строки этой матрицы остаются обязательными, включая удалённый возвратный via и поиск возврата вне локального окна; план не изменяет статусы приёмки.

Контроль 2026-11-06: [малая смешанная модель общего возврата](../../evidence/p7-shared-return-local-far-2026-11-06.md) прошла физические гейты для двух возбуждений на 1/10 кГц относительно объёмного порядка 16. Это шесть конечных призм с локальными тетраэдрами, не принятый автоматический распределённый 2D-маршрут. Отказ относительно порядка 8 зафиксирован; статусы семейств ниже не повышены.

Что реально поддержано, что только моделируется геометрически, что проверяется и что отвергается.
Статусы актуализированы **2026-11-05**; редакция контракта **2026-11-04** сохраняется и заменяет редакцию 2026-11-02. Численные результаты не обновлялись; исторические статусы и условные решения 2026-11-03 сохранены. Документ живой: меняется вместе с evidence, не вместе с планом.

## Актуализация реализации 2026-11-05

Заменяет оперативные ограничения сводки 2026-11-04. Численные приёмки строк не
повышены. Таблицы ниже сохраняют исторические результаты; «не поддерживается»
в старой строке не означает отсутствия всех общих геометрических механизмов.
Обратное тоже неверно: общая сетка/оператор не доказывают готовый автоматический
маршрут, полосу и восстановление для каждого случая. **Полное покрытие кодом
и физическая приёмка всей матрицы пока не подтверждены.**

N-port/group DSL, mixed foil/volume, конечные pad/barrel, компоненты и проводящее
разбиение реализованы. Для допустимых коридоров есть 2D/локальный 3D гибрид;
общая mixed-область сохраняет совместные поля и исходные объёмные проверки.
Via в этом пути объёмные; переход на 2.5D отложен.

На полной STM32 геометрия проходит. Последнее магнитное действие на двух
DC-распределениях физических портов остановлено по времени 1800.047 с, без
сертификата действия или полного AC-ответа. Private peak native поддерева
1 328 381 952 Б относится к незавершённой попытке; память полного экстрактора
не принята. Приемлемое время не достигнуто, P7 открыт.
[Актуальный результат](../../evidence/p7-adaptive-magnetic-2026-11-05.md).

## Как читать статусы

| Статус | Значение |
|---|---|
| **Поддерживается** | Класс считается, есть принятый или условно принятый результат в заявленной полосе |
| **Моделируется геометрически** | Медь/отверстия/слои попадают в численную модель, но принятого результата для класса нет |
| **Проверяется** | Прогон существует, обязательные гейты не пройдены |
| **Не поддерживается** | Явный отказ планировщика или отсутствие механизма |
| **Деградация (≤20%)** | Независимо подтверждённое приближение в явно указанной области, с предупреждением |
| **Unverified** | Модель/результат есть, но точность или полоса не подтверждена; проценты ошибки не обещаются, строка не закрыта |
| **Refused** | Модель не построена; причина и стадия обязательны, положительный кейс не закрыт |

Все строки основных случаев обязательны для P7, включая connector/pad. Явные исключения — только full-wave/антенны/излучение, электрически большие или многомодовые структуры и >10 ГГц. Универсальность проверяется общими правилами, а не ветками под конкретную плату.

«Принято» всегда означает: есть документ приёмки, гейты не ослаблены, полоса и допущения указаны.
Отсутствие строки не означает поддержку.

## Реализация 2026-11-04 — ограничения прежних строк уточнены

Строки ниже сохраняют исходный статус физической приёмки. Таблицы различают реализованные возможности и физическую приёмку. N-port planner и явный section mapping реализованы. Native role=reference означает один математический gauge; другие физические опоры сохраняются независимыми координатами. Ограниченный трёхпроводниковый gauge control прошёл sensitivity (C0.1954%); это не приёмка произвольных нескольких опор.

| Класс | Что изменилось | Что остаётся |
|---|---|---|
| Связанная группа / ветвь | 5-port group и 3-port branch geometry tests проходят; общий адаптер `.si().channels([...])` | Полная EM/common-band/реальная DDR-group приёмка |
| Несколько опор | Явные conductor-end mappings, отдельные potential/current coordinates, mixed-polarity contacts | Общая board-level физическая проверка и удалённые соединения |
| Differential | Existing layered target подключён к joint four-port leg-to-return S50 | Independent physical acceptance, mixed-mode characteristic impedance и SI/timing |
| Split-return | Reference-free gap сохраняется в bounded joint event, same-net disconnected returns не welded | Реальная capacitive/remote-return accuracy; manufactured EQS test не заменяет её |
| Частотная адаптация | Helper с holdouts/deadline/budget и общей интерпретацией запроса | Production independent evaluator, skin/HF и common band |

Evidence: [2026-11-04 integration](../../evidence/p7-universal-integration-2026-11-04.md). Неподтверждённые результаты не повышены до accepted. Исторический D1 resume отказал по domain delay.

Дополнение: [автоматический foil-путь](../../evidence/p7-automatic-foil-2026-11-04.md)
подключён для распределённого бокового возврата без barrel/component attachments.
Общий оператор сохраняет конечные плоскости и независимые острова; допустимы
2–8 слоёв меди, четырёхслойный численный контроль прошёл. Выход — точные
проверенные S-точки 1–10 кГц, `partial/unverified`, без разрешения интерполяции,
соединений или физической SI-приёмки. Это расширяет реализацию, но не закрывает обязательные строки
по пространственной точности, реальным платам и широкой полосе.

Смешанный foil/volume runtime с конечными контактами и совместный SI runtime группы реализованы. Компактный mixed-контроль и исходный автоматический bend прошли полные невязки; физическая точность группы и mixed board остаётся открытой. Actual-addon cold/memory/disk exact-grid cache прошёл: после перезапуска native solve не вызывался. Профиль меди по skin depth служит предварительной проверкой сетки, физическая skin/HF-полоса открыта. [Mixed conductor](../../evidence/p7-mixed-conductor-2026-11-04.md), [Copper mesh](../../evidence/p7-copper-mesh-profile-2026-11-04.md)

Результаты новых геометрических контролей и D1 resume приведены в [отчёте продолжения](../../evidence/p7-continuation-2026-11-04.md).

## Основные случаи

| Случай | Физическая приёмка | Реализация и оставшаяся проверка |
|---|---|---|
| Земля под дорожкой (сплошная) | **Поддерживается (условно)** | Однородный участок → 2D-сечение; straight/bend приняты в низкой полосе. D1 continuous ещё открыт, переносить на любые длины нельзя |
| Изгиб 90° | **Поддерживается (условно)** | Принят как coupon; не гарантия для произвольной геометрии |
| Дорожка 45° | **Поддерживается (условно)** | spatial-delay 2.174198% принят при пороге 3% (2026-11-03) |
| Связанная пара (два сигнала) | **Поддерживается** только для явного coupled-сечения | Явное coupled-сечение принято в своей полосе. Автоматический N-port planner и joint four-port differential runtime реализованы, автоматическая пара по плате требует независимой EM-проверки |
| Земля с разрывом под дорожкой | **Моделируется / проверяется** | Bounded joint event удерживает разрыв и обходы и различает острова. После исправления выбора resume D1 вернул domain 4 с внутренней сходимостью в 1–10 кГц. В исторической проверке domain 1 → 2 был FAIL. Matched full joint и hybrid завершены. Four-port/open сравнения 1.25208%/1.45596%. Strict loaded replay после правки прошёл на обновлённом joint state. Joint spatial loaded-reactance отказал, приёмка открыта |
| Земля сверху и снизу — явное идеальное сечение | **Поддерживается** | `a.line({kind:"stripline"})`; две плоскости сводятся к общему reference |
| Земля сверху и снизу — авто по реальной плате | **Unverified** | Базис сохраняет отдельные координаты плоскостей. Нужен подтверждённый маршрут на реальной плате с фактическими связями между плоскостями |
| Сверху+снизу + разрыв на одном/двух слоях | **Не поддерживается** | Раздельные координаты и bounded split-return реализованы. Совместный сценарий двух плоскостей с разрывами требует своего контроля |
| Сшивка / via fence | **Моделируется геометрически** | Реальные barrel/pads внутри окна считаются; универсального fence-экстрактора и приёмки нет |
| Return via рядом с дорожкой | **Поддерживается (условно)** | spatial-delay 2.763860% принят при пороге 3% (2026-11-03) |
| Signal via / смена слоя | **Моделируется / проверяется** | Via corridor реализован, приёмки канала нет |
| Ветвления | **Моделируется геометрически** | Трёхпортовая ветвь проходит геометрический контроль. Электрическая приёмка всех ветвей и нагрузок открыта |
| Земля подключена на другом конце платы | **Unverified** | Remote physical bypass прошёл геометрическую проверку. Внутренний sparse foil-модуль с потоковым LQ и обогащением прошёл полную невязку малого двухслойного купона на 10 кГц; этот путь не использует прежний dense cap 64. Автоматический planar foil и смешанный foil/volume runtime реализованы для допустимых входов. Многослойный STM32 и пространственная точность открыты. Историческая нижняя оценка fine electric enclosing ROI — 28 513 МиБ; новая редукция не подтверждает устранение этого field-бюджета. [Оператор и ограничения](../../evidence/p7-foil-reduction-2026-11-04.md) |
| Под дорожкой меди нет совсем | **Unverified** | При разрешимых исходных физических контактах отсутствие локального return-коридора выбирает общую область с независимыми островами. Геометрический контроль прошёл; численная точность ёмкостного/удалённого возврата ещё не принята |
| Несколько опор / две земли | **Unverified** | Независимые координаты, явные conductor-end mappings и mixed-polarity contacts реализованы. Нужна общая проверка физических соединений и восстановления токов |
| Широкая опора (wide return) | **Проверяется** | Приняты только совместные коэффициенты C1; реальный канал не принят |
| Окружающая медь | **Моделируется геометрически** | Внутри окна (~стек + запас) — вся медь всех слоёв; вне окна в оператор не входит |
| RF-сечение (BandAmp) | **Поддерживается** в узкой полосе | 500 МГц–1 ГГц, quasi-TEM, только сечение; полный RF-канал и ground-via — нет |

| Разрывы опоры сверху и снизу одновременно | **Не поддерживается** | Требуемый кейс: нужна модель двух опор и их физических соединений |
| Blind/buried via | **Моделируется геометрически** | Span прошёл три геометрических теста и шесть отдельных DC случаев. Полная EM-проверка signal/return, antipad и stub открыта. Coax skin-transition проверяется отдельно |
| Разъём/пад (connector/pad transition) | **Не поддерживается** | Переход дорожки в пад/разъём; отдельный класс не реализован |
| Дифференциальная пара | **Частично** | Явное coupled-сечение принято. Layered differential подключён к joint four-port leg-to-return S50. Физическая приёмка автоматической пары и смены опоры открыта |
| Смена опоры (reference swap) | **Не поддерживается** | Геометрия и независимые координаты поддерживают раздельные острова. Переход с доказанным физическим путём возврата между слоями/плоскостями ещё не принят |
| Нет локальной опоры: поиск возврата по цепи | **Не поддерживается** | Правило в плане §4.0; реализация не начата |
| GND/AGND/PGND с физическим соединением | **Не поддерживается** | Разные острова и ориентированные контакты представимы. Автоматическое извлечение физического соединения и его R/L в этом сценарии требует проверки |
| Несколько переходов опоры (AGND→PGND→GND) | **Не поддерживается** | v1: до 8 переходов на канал; каждый — событие + физическое соединение; больше — отказ |

## Дополнительные обязательные приёмки

| Случай | Фактическое состояние | Что требуется для закрытия |
|---|---|---|
| Ёмкостный/смешанный возврат через разрыв | Bounded joint geometry и manufactured EQS control реализованы. Общий автоматический путь не принят | AC multiport, ток смещения/баланс заряда, физические C, отдельная проверка DC-разрыва |
| Component bridge (R/C/ferrite) | Явные R/C/L attachments, captured pins и DSL/planner реализованы. Поиск поддерживает до восьми рёбер и промежуточные острова | Извлечённые контакты + заданная модель компонента, общая полоса и отсутствие weld |
| PDN multiport | Есть условные finite-ROI 1–100 кГц результаты. Отдельный DC endpoint сохраняет матрицу физических электродов и независимые острова; явные R/DCR и открытый C проверены на ограниченном купоне. Полный PDN-путь не принят | Полный обязательный сценарий, многопортовая композиция/наблюдения, взаимные связи, DC/AC overlap и recovery; [границы DC-пакета](../../evidence/p7-dc-endpoint-2026-11-04.md) |
| Небольшая связанная группа, branch/meander | Реализованы N-port планирование и joint preparation списка каналов, пройдены геометрические контроли | Подтвердить независимые mutual/crosstalk и токи всех ветвей в общей полосе |
| 2/4/6/8 слоёв, асимметрия и конечные края опор | Полное покрытие не подтверждено | Манифест представительных комбинаций; несколько опор не сводятся к одной без проверки |
| Адаптивная полоса по DSL | Event 5 подтвердил intrinsic local 1–10 кГц на свежем кэше с независимым replay и 12 интервалами. Segmented W6 и owner loss интегрированы и проверены TS тестами. Физическая общая и широкая полосы открыты | Все требуемые интервалы §1.1/§F плана, новые holdouts, явные непокрытые интервалы |
| Инварианты универсальности | Манифест перечисляет все 42 случая, часть подготовительных артефактов привязана. Полная матрица численных проверок открыта | Перенос/поворот, ID/порядок терминалов, CAD-разбиение меди, gauge и сдвиг разрезов |

Для каждой основной и дополнительной строки manifest A фиксирует ID сценария, геометрию/материалы/порты, требования DSL, полосу, observables, reference и его неопределённость, гейты, ресурсы и evidence. Численные приёмки привязаны к версии кода. Отрицательные контроли (битая геометрия, отсутствующая модель пути) должны корректно отказывать, но не заменяют положительные сценарии.

Закрытие всей матрицы требует положительной приёмки всех обязательных классов и их перечисленных комбинаций. Статусы «геометрически моделируется», «проверяется», `unverified` и `refused` не считаются закрытием. Новая редакция документа не повышает статус старого результата.

## Опоры и переходы

### Смена опоры

| Случай | Что происходит | Что делаем | Статус |
|---|---|---|---|
| Тот же net, разрыв с обходом | Возврат меняет путь, но не net | Событие + обход; окно должно включать обход | Моделируется / проверяется |
| AGND → GND через разрыв | Возврат идёт через точку соединения (звезда, перемычка, via) | Найти точку; если вне окна — расширять или отказ | Не поддерживается |
| Несколько переходов (AGND→PGND→GND) | Несколько смен опоры подряд | Каждый переход — событие; v1 до 8; больше — отказ | Не поддерживается |
| Смена слоя (signal via + return via) | Возврат переходит на другую плоскость | Событие с двумя via; явная модель соединения | Моделируется / проверяется |
| Разрыв без гальванического соединения | Возврат только ёмкостный | Модель неоднородности с большой common-mode нагрузкой или отказ | Не поддерживается |
| Смена опоры без найденного соединения | Проводящий путь не найден; проверить ёмкостный/смешанный AC-путь | При неразрешённом пути — диагностика по контракту, виртуальную землю не подставлять | Не поддерживается |

### Две опоры: как моделировать соединение плоскостей

| Тип соединения | Модель | Когда применять |
|---|---|---|
| Короткая широкая перемычка / несколько via | Сосредоточенное R/L: малый 3D-блок или аналитическая оценка | Размер соединения мал по сравнению с длиной волны в полосе |
| Длинная узкая перемычка | 2D-сечение (линия передачи) между блоками плоскостей | Соединение длинное; R/L/C распределены |
| Край платы | Распределённое соединение: на низкой частоте R/L, на высокой — по ширине | Полосу указать явно; одним via не заменять |

**Объединение опор:** только после теста «две опоры против одной»: изменение S/задержки/наводки ≤2% в рабочей полосе и сопротивление соединения мало по сравнению с сигнальным. Иначе — отдельные опоры и явная модель. Имена GND/AGND/PGND не соединяют.

## Чего не хватает для универсальности

1. Несколько опор и их физические соединения (via/медь), а не эквипотенциальное слияние.
2. Возврат за пределами локального окна: расширение домена с критерием или распределённая plane-модель.
3. Приёмка ветвлений; 45°/via уже приняты условно при 3%.
4. Общая полоса section/local и переход skin-режима.
5. Ресурсы полного автоматического пути: последний магнитный прогон STM32 не завершился за 1800 с; наблюдённая память незавершённой попытки не подтверждает полный экстрактор. Исторические 8.7 ГБ не являются текущим измерением.
6. Blind/buried via, разрывы сверху и снизу, разъёмы/пады, дифференциальные пары, смена опоры и несколько переходов опоры.
7. Независимые эталоны и бюджет ошибки для каждого класса.
