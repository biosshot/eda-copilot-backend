## Разделение работ

Ведущий агент задаёт контракты и ревьюит изменения. Исполнители получают ограниченные пакеты и непересекающиеся файлы. Общие native/section структуры меняются последовательно после согласования интерфейса. W0 независим от W1; дальнейшие пакеты не запускаются целиком поверх неподтверждённого базиса. Мелкие исправления выполняются при ревью, крупные возвращаются исполнителю.

## Исходные ограничения до W1–W3

- `board-channel-plan.ts` использует четыре контакта, один signal island и два внешних порта; явный общий контракт ещё не означает поддержку N-port.
- `segmented-channel.ts` требует один reference в magnetic support; удалить guard без нового согласованного basis нельзя.
- Автоканал фиксирован 1–10 кГц, local preparation имеет отдельные low-band ограничения; простая замена частотных констант не реализует широкополосность.
- `electricAirMarginM` передаётся planner → board_mesh Request → board_prepare. Новый холодный PASS пока отсутствует; перед D1 проверить фактический addon/dist producer.

Непосредственный результат первой партии: W0 и фундамент W1, затем ревью W2. Ничто из этого само по себе не закрывает D1/P7.
